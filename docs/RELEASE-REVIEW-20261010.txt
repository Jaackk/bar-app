After inspecting all changed documents and resolving catalogue proposals:
  python scripts/check-menu-updates.py --state-dir <local-evidence-directory> --accept-baseline

The tool tracks both URL changes and PDF byte changes at an unchanged URL. Source
errors are failures, never empty menus. The reviewed baseline survives failures.
Its baseline is a document fingerprint record, not approval of recipes/counts.
Public documents must never reset local counts, photos, lists or house specs.
The installed app has no automatic content sync. Safe publishing/cache merging
is required before a website change can be delivered to staff phones.
