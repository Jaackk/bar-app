## Stock workflow

The list remains a compact working list. Product selection opens separately; +/- buttons show what is already selected. A product can be created directly from that picker. Both lists persist independently and support custom entries, direct quantity editing, swipe removal, copy, share and explicit clearing.

Products & photos provides add/edit/delete and the native Photos picker. Images are stored on-device, downsampled to 800 pixels, and can be removed independently. The shared product record drives both lists, universal Search and manager Stocktake. Product deletion does not remove saved list entries. No stock shortages populate either manual list.

## Search

Offline search includes shared products, common language stopwords, accent-insensitive names and one-character typo tolerance for longer words. Wine pairing search uses transparent style guidance: steak/beef, fish/seafood, poultry, shellfish, vegetables and other pairings. The UI distinguishes inferred pairings from menu facts. No AI account, API key, network call or recurring cost is required.
