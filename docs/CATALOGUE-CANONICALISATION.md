# Rockwater stock catalogue canonicalisation

The menu imports retain their original recipe wording. BAR's catalogue migration resolves that language to physical stock products without changing cocktail specifications.

| Imported record | Canonical stock product | Treatment |
| --- | --- | --- |
| Muddled Lime / Lime wedge / Lime wheel / `spec-lime` | Limes | Recipe and search aliases; no separate SKU. |
| Orange Slice | Orange | Serving form resolves to the fruit. |
| Blend Passionfruit | Passion Fruit Puree | Recipe wording resolves to the stocked puree. |
| OJ / Orange Jucie | Orange Juice | Abbreviation and typo consolidated. |
| Apple / Pineapple / Tomato | Apple Juice / Pineapple Juice / Tomato Juice | Source recipes use juice. |
| Belnd Triple Sec | Triple Sec | Typo consolidated with the liqueur. |
| Peach Liq | Teichenne Peach Liqueur | Alias consolidated. |
| Peroni | Peroni Nastro Azzurro 5% | Generic recipe label resolves to the stocked variant. |
| Blend Coffee / Coffee (espresso shots) | Espresso | Recipe component resolves to one operational item. |
| Soda | Soda Water | Alias consolidated. |
| Angostura | Angostura Bitters | Alias consolidated. |
| Disarrono | Disaronno | Typo consolidated. |
| Orgeat Syrup / Gomme | Orgeat / Gomme Syrup | Duplicate labels consolidated. |
| Rose Prosecco | Prosecco Collezione 96 Rosé, Masottina | Recipe reference resolves to the venue product. |
| Veuve Cliquot Brut | Veuve Clicquot Brut Yellow Label | Typo consolidated. |
| Old Forestor | Old Forrester Bourbon | Typo consolidated. |
| Salcombe Rose | Salcombe Rosé Sainte Marie | Alias consolidated. |
| Chilli Infused El Jimador Blanca | El Jimador Blanco | House infusion wording resolves to base stock. |
| Fruit / Desired Fruits / Desired Puree / Desired Syrup / White Wine / Cremant / Hot Water / Pineapple Foam | — | Recipe-only/generic language; no standalone stock SKU. |

Daily Dose labels are preserved as clearly named juice products (`Daily Dose Lime Juice`, `Daily Dose Lemon Juice`, and `Daily Dose Pink Grapefruit Juice`). They retain `DD` aliases for recipe and search resolution.
