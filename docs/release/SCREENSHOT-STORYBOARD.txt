CAPTURE PROCEDURE
Run scripts/validate-mac.sh at the NEW final commit, then use the screenshot route
in docs/release/MAC-VALIDATION.txt. Capture a supported Pro and smaller iPhone for
layout QA. Keep original PNGs plus device/iOS/build/SHA in the capture folder.
For simulator captures: xcrun simctl io DEVICE_UDID screenshot OUTPUT.png
Use the actual App Store Connect size slots for the supported devices. Confirm the
current upload dimensions before designing final caption canvases:
https://developer.apple.com/help/app-store-connect/reference/app-information/screenshot-specifications/
On a physical iPhone, also verify the images at real reading size and accessibility
text sizes. Do not crop or erase defects to produce a clean marketing screenshot.

FINAL CHECK

supplier/cloud claims; correct specification label; whole bottle; useful first three
images; support/privacy URL working. Final store graphics wait for native validation.
